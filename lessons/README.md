# Sample lessons

Load one with `typist101 --lesson /usr/share/typist101/lessons/FILE.txt`, or drag the file into the window. `*-simplified.txt` and `*-traditional.txt` are separate typing exercises.

- `jing-ye-si-*`: Li Bai, *Quiet Night Thought* (Tang dynasty; public domain).
- `lu-xun-leifeng-*`: Lu Xun, *On the Collapse of Leifeng Pagoda* (1924; public domain). Traditional text from [Wikisource](https://zh.wikisource.org/wiki/論雷峰塔的倒掉); simplified version converted with OpenCC.
- `alice-chapter-1.txt`: Lewis Carroll, *Alice's Adventures in Wonderland*, chapter 1 (1865; public domain). Text from [Project Gutenberg ebook 11](https://www.gutenberg.org/ebooks/11); paragraph line wrapping and italic markers removed.
- `home-row.txt` and `mixed-practice.txt`: original exercises for this project.
